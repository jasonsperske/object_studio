# Bundled font

`Web437_IBM_VGA_8x16.woff` is the IBM VGA text-mode ROM face (code page 437, 8×16 cell) from
**The Ultimate Oldschool PC Font Pack v2.2** by **VileR** — <https://int10h.org/oldschool-pc-fonts/>

Licensed under [Creative Commons Attribution-ShareAlike 4.0 International](https://creativecommons.org/licenses/by-sa/4.0/).
The full licence text is in `LICENSE-oldschool-pc-fonts.txt`.

The font is used unmodified, and only by the **3D Studio DOS** theme. Because it is a bitmap
design traced to outlines, it is pixel-exact at 16px and whole multiples of it — which is why that
theme sets a single 16px text size throughout, as a real text-mode UI did.
